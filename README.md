# 🏥 PulseVision AI – Smart Medical Insight Assistant

PulseVision AI is an AI-powered healthcare assistant that analyzes medical images along with patient symptoms to generate a detailed health report.

---

## 🚀 Features

- 📷 Upload ECG / X-ray / MRI images
- 👤 Enter Patient Name & Age
- 🧠 AI-based Disease Prediction (Hugging Face)
- 📊 Confidence Score Display
- ⚠ Risk Level Detection (Low / Medium / High)
- 💡 Health Suggestions
- 🩺 Doctor Recommendation
- 📝 Symptoms Analysis
- 📄 Downloadable PDF Report
- 🖼 Image Preview

---

## 🛠 Tech Stack

- Python
- Hugging Face Transformers
- Gradio (UI)
- Pillow (Image Processing)
- ReportLab (PDF Generation)

---

## 📌 How It Works

1. Upload a medical image (ECG/X-ray/MRI)
2. Enter patient details (Name & Age)
3. Provide symptoms (e.g., chest pain, dizziness)
4. AI analyzes the image
5. Generates:
   - Prediction
   - Risk Level
   - Doctor Suggestion
   - Health Advice
6. Download the PDF report
